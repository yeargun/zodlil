Zod,
compiled.

The zod@4.4.3 classic API, rewritten in LilScript and built by the one LilScript compiler, with nothing minifying after it. Internals are mangled; the public API stays named. The size bar is upstream zod with the same public surface and the English locale only, minified by Oxc, Terser and esbuild: the smallest of the three.

Parse,
not inferred.

Same 48-object batch, 400 rounds per sample. Quiet median after discarding the first 3. Output must match official zod@4.4.3. Ratio is lane / official (lower is faster). The port parses several times slower than official zod: the rewrite dropped the fast paths that were JavaScript source compiled with new Function (forbidden under a strict CSP), and upstream compiles its object parsers that way. On this shared host, back-to-back runs disagree by up to 2× on the ratio, so read it as an order of magnitude. Size comes first in this port.

              How to read the rows. The shipped row is zod.core.js,
              compat.js and index.js, each compressed on its own, as a CDN
              serves them. The esbuild bundle row is the conservative figure: esbuild re-prints our
              already-minified core when it bundles the package. The mangle-off row compiles the same
              source with lilscript.nomangle.toml. The bar's z.core is
              upstream's whole core namespace, of which the port offers 42 names, so the bar carries
              about 1.2K Brotli of surface the port does not ship; the port's own additions, such as
              z.visit, count against it.
